# 功能与状态

唯一当前基线见根目录baseline.json。下面是本候选最终行为，不通过旧源码文件名猜测采用了哪种历史方案。

- 战后10秒不遇敌保护与37.5%亮度的在队角色闪光，Boss和小怪不闪；十里香原生60秒效果期间停用新增保护和闪光。系统设置可开关，重启保留。
- 手柄快走起步、A/B与通用摇杆输入修正；按住鼠标八方向行走、窗口边缘与跨场景续走、普通指针显示和远距离抓手提示。抓手提示不扩大真实交互距离；单击寻路和尖角自动贴边未做。
- 进入战斗提速，画面/UI可提前开始，保留普通/蛇怪遇敌叫声与随后接上的音乐。
- 地图小怪减速和较小追击范围，原生剧情飞行、追击过场及乘莲速度不被全局拖慢。普通AI判定与脚本运动区分，不能恢复旧错误偏移或全局速度限制。
- HP/MP成长上限9999及四位数字布局；战后存活在队角色各恢复上限6%的HP/MP，不复活；随机属性成长保持原概率，累计门槛减半。
- 合体攻击沿用原招式目标、动画和差异公式，追加随成长的加成；保留原扣HP，不额外扣MP；不采用全体化或普攻保底的废弃方案。
- 普通群攻死亡表现同时启动、重复声音合并，奖励仍按原规则结算；特殊剧情模板回退。蛇怪左上坏帧修正在EXE帧选择处。
- 地图覆盖梦境、再入罗刹前/后、荷花池。沿真实移动逐步揭雾，半径60px；人物为清晰金色小人。荷花运输中途采样，不能把瞬移两端插值成探索路线。
- 拼图标题未进入隐藏，进入后整块显示，保存/读档尊重对应进度；名称可共享逻辑组，但楼层地形和探索不得串层。

当前新增标题逻辑有17个再入场景、16种梦境进入组合及存档回滚/缺图安全的离线检查，最终实机反馈待补。地图风格/定位/迁移等已有离线证据，不能据此宣称全部地图或所有硬件实机通过。实时剧情目标和金银出入口方向指引尚未全面完成，其他迷宫仍待接入。
