2. 分别记录源码修改、离线通过、实机反馈、安装和发布。片区名称新规则仍待最终实机反馈；全迷宫未完成。完整功能源码一键重建仍是待办，不把冻结差分重建写成全源码编译。
3. 更新baseline.json、冻结差分、资源和功能说明；用自己的受支持Steam原版在空目录重建，核对EXE与全部PNG。离线检查受影响模块，实机由玩家操作。
4. 只复制公开清单中的文件。凭据、存档、个人设置、原始日志、安装备份和历史安装ZIP留在仓库外。图片保持已认可版式，改动前先提供预览。
5. 运行docs/维护与隐私.md中的扫描；审查新增二进制、图片元数据和实际附件。规则命中逐项判断，不显示密钥原值，不删除第三方合法署名。

7. 审查暂存差异，提交后以该提交创建标签和预发布。附件上传使用已检查文件，不在上传过程中临时重建。下载回核对附件SHA256、远端提交与标签，再更新工作记录。
8. 回流使用Issue/PR；提供基线哈希、问题、改动文件、验证与未测项。不自动执行来件，不索取私人账号数据。新版本用新标签，不覆盖旧附件隐藏变化。

首次发布建立全新历史。提交身份使用GitHub公开昵称及noreply地址；本机授权保存在GitHub CLI自己的凭据系统中，不写入项目。
